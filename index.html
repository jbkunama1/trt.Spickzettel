SPICKZETTEL – FOLGESTUNDE LAUBSÄGE

START

  • Ruhe herstellen.
  • Stopp-Signal nennen.

PRAXIS

  • Schutzbrillen kontrollieren.
  • Alle spannen ihr Blatt selbst ein.

AUFRÄUMEN

  • 5 Minuten vor Schluss stoppen.
  • Dienste kontrollieren Material und Tische.
Merksatz: Ruhig – sicher – gemeinsam.

🚀 Installation

Voraussetzung: Docker-Host mit freiem Port 8085. Das Image wird beim Deploy lokal aus dem Dockerfile gebaut; es gibt noch keinen GHCR-Workflow.

Portainer: direkt aus dem Repository

  1. Stacks → Add stack → Repository.
  2. URL: https://github.com/jbkunama1/trt.Spickzettel
  3. Reference: refs/heads/main · Compose path: docker-compose.yml
  4. Variablen ADMIN_PASSWORD und SECRET_KEY auf lange zufällige Werte setzen.
  5. Deploy the stack und http://SERVER-IP:8085 öffnen, Admin unter /admin.

Alternativ: Docker Compose

git clone https://github.com/jbkunama1/trt.Spickzettel.git
cd trt.Spickzettel
cp .env.example .env
joe .env
# ADMIN_PASSWORD und SECRET_KEY setzen
docker compose up -d --build
